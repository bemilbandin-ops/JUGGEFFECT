## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`

## Features Included

- **Quick Visual Presets**: Apply pre-calibrated CV configurations like *LED Tracker*, *Neon Cyberpunk*, *Spectral Smoke*, *Strobe Echo*, *Wormhole Vortex*, and *Stardust Cascade* instantly offline.
- **AI Scene Auto-Tuner (Beta)**: Auto-analyzes the environment using Gemini 3.5 Flash, providing customized settings recommended for your lighting conditions.
